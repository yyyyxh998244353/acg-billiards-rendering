# H100 动态路径追踪优化

基线提交为 `d8ce2f9`。三轮试验使用 `i5` 的单张 H100 PCIe、驱动 580.178.04 和 CUDA 12.8.93，编译目标为 `sm_90`。编译在 `i2` 上完成。计时以球体线扫和 1280×720、2 spp 完整路径为准。第 27–34 帧和第 67–74 帧分别使用采样种子 `4698817` 和 `7930513`，物理轨迹以种子 `42` 按 60 FPS 导出。每种构建在每段做两轮交替测量，每轮剔除一个预热帧。`render_ms` 为 CUDA 事件计时，整帧耗时包含准备、上传、渲染和回读。计时时关闭 PPM 写盘，图像对照另行写出 PPM。

## 选定构建

```sh
nvcc -O3 -std=c++17 -arch=sm_90 -maxrregcount=128 render.cu -o render_h100
```

分包安装的 CUDA 工具链在链接时使用其运行时库目录。本次试验通过 `-L<toolkit>/lib` 链接静态 CUDA 运行时。每块使用 128 个线程。

| 32 个计时样本 | 基线 | 128 寄存器上限 |
|---|---:|---:|
| 核函数 p50 | 16.782 ms | 16.134 ms |
| 核函数 p95 | 17.235 ms | 16.584 ms |
| 整帧 p50 | 16.978 ms | 16.333 ms |
| 整帧 p95 | 17.447 ms | 16.777 ms |
| 整帧在 16.67 ms 内完成 | 6/32 | 20/32 |

两段各八个姿态的 PPM 在三种构建中逐帧 SHA‑256 一致。开球段两轮配对核函数耗时降幅为 3.80% 和 3.81%，整帧降幅为 3.62% 和 3.88%。散球段两轮核函数降幅为 3.69% 和 3.81%，整帧降幅为 3.55% 和 3.80%。`ptxas` 报告寄存器数从 151 降到 128，栈帧从 32 B 增到 96 B，报告的 spill store 和 load 分别为 124 B 和 136 B。

## CPU 经验移植和调度对照

| 候选 | 开球段两轮核函数耗时降幅 | 散球段两轮核函数耗时降幅 | 图像对照 |
|---|---:|---:|---|
| 中央点光阴影只查球体 | −0.05% / −0.17% | −0.05% / −0.08% | 六个姿态逐帧一致 |
| 中央点光阴影只查球体，加省略阴影法线 | +0.10% / −0.12% | −0.15% / −0.27% | 六个姿态逐帧一致 |
| 顶视台布快捷求交 | −7.45% / −7.33% | −7.39% / −7.53% | 16/16 帧有差异，481 个颜色通道值变化，最大差 34 级 |
| 每块 64 线程 | −1.87% / −1.69% | −2.04% / −1.94% | 16 个姿态逐帧一致 |

阴影两版均用 153 个寄存器，顶视台布版用 155 个，三者均无 spill。顶视台布版的点光阶段控制图一致，材质阶段的字节差异触发作业退出。已撤回 CUDA 阴影、顶视台布和 64 线程块的源码试验。

|---|---|---:|
